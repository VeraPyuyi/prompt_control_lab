# 固定控制诊断的跨提示组预测

[English](README.md)

这个可运行案例复算预先固定的预测，在新提示组上能否准确描述控制诊断的相对效用。
它与[测量价值案例](../measurement_value/README.zh.md)对应两个问题：预测能提供多少信息，
以及这些信息是否值得付出测量成本。

考察量为 `G = AUC(状态诊断) - AUC(参考解答损失)`。两类固定状态分数分别比较完整控制特征、
廉价特征、统一开发组均值和零基线。脚本只应用传入的固定预测，再核对行为标签。

```console
python -S scripts/run_transfer_prediction_case.py --input docs/case_studies/transfer_prediction/synthetic_test.json --out transfer-example
```

当前例子明确标为**合成测试数据**，用于验证接口。新的 GSM8K 实验记录需在原始证据独立重放通过后，
从 `publication/compact_case.json` 导入；本目录当前没有新的 GSM8K 实证结果。脚本只依赖 Python
标准库，生成 JSON、完整逐对 CSV 和中英文报告，并通过使用新的输出目录保留旧结果。

输入区分历史观察、锁定预测和独立确认，明确端点是否共享，并携带外部预测锁的 SHA256。
独立提示确认要求端点不共享。每对提供固定分数、两个端点的风险或直接提供风险变化标签，以及四种固定预测。
只有变化标签时，风险改善和恶化的方向计数保留为空。锁定预测阶段不提供行为标签。
具体字段见英文说明。

无定义 AUC 保留为空，完整展示逐对结果与共同有效覆盖。相对统一均值的误差改进对应逐对信息，
相对廉价预测的改进对应控制测量的额外信息。独立性、原始张量与 token 重放、校正后的统计区间，
由完整研究复现包另行核验。该紧凑案例不会把输入声明或点估计自动升级为独立预测成功。

[原控制理论论文](https://arxiv.org/abs/2606.17762)提供带适用条件的响应与重建结果。
实验中的经验响应特征仍需行为验证，控制时域 `T`、生成上限 `L` 和评估预算 `B` 分别表述。
预测误差下降是否带来评估效率改善，需要在配套测量价值案例中继续计入探针、评分和行为检查成本。

代码与合成例子沿用仓库 Apache-2.0 许可。导入真实记录时应保留输入、预测锁、独立重放与来源哈希，
以及原数据许可说明。
