# Real Server Evidence Snapshot

This public-safe case study was generated by a read-only scan of an existing PEOC/A800 experiment tree. The scan indexed 911 files across seven adapters and then reduced them to aggregate metrics, interpretation roles, a snapshot hash, and claim boundaries.

No model weights, private prompts, dataset records, server absolute paths, or hidden reasoning are included. The portable source identity is path-independent, and its snapshot hash is `sha256:f06e78767d7d399ed5d120de9671ea9ec2881c8e2c41a161ad6bfb716e914367`.

## What the snapshot supports

- Mechanism interpretation: soft/hard projection, time-varying structure, capacity controls, and agent episode structure.
- Stability interpretation: stationary versus heterogeneous trajectory decay and fitted Riccati/DARE surrogates.
- Boundary interpretation: teacher-forced versus free-generation pilots and their stopping rules.
- Uncertainty interpretation: selective-risk behavior over 360 seed rows.
- Decision interpretation: a 72-row frozen deployment analysis and its fail-closed rationale.

The snapshot does **not** establish universal prompt improvement, strict causality, global LLM convergence, or operational-model stability. `observed` and `inconclusive` retain their original evidence meaning; both can still be useful for explaining scope and choosing the next experiment.

Adapter validation marked 68 generation records and one trajectory-side record as schema-incomplete; they remain counted as source evidence but are not silently promoted to validated findings.

The three-seed SFT checkpoint pilot now has a pinned, hash-verified Qwen2.5-0.5B-Instruct snapshot, deterministic train/validation/withheld inputs, the current `0.2.0a1` wheel, and a dedicated dependency environment. It was deliberately not launched because two consecutive read-only samples ending at `2026-08-24T18:13:41Z` still reported one running queue job and one pending queue job, with an active GPU compute process. This deployment-ready but queue-blocked state is recorded in [sft_pilot_status.json](sft_pilot_status.json); no checkpoint result is claimed.
