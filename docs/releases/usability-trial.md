# First-user usability trial / 首次使用者试用

Status: **pending recruitment / 尚待招募**. The project owner confirmed that no participants are currently available. No messages or invitations were sent. Automated browser checks do not count as human trials.

Target: five people who have not used PCL; at least four independently finish configuration → run/import → explanation → export. Record language and whether a participant is primarily an ordinary user or researcher. At least one English and one Chinese session should be represented.

Each participant starts from the installation guide in a clean directory. Give the task: “Use the offline example, explain whether the evidence establishes an improvement, change or import a task, and save a readable result.” The offline first-completion target is five minutes. Record assistance and failure causes; do not infer success from elapsed time or a screenshot alone.

Do not collect participant names or credentials in the public record. Use P01–P05, obtain consent for notes, and keep quotations optional. Real API calls are an optional separate task with a declared budget and participant-provided credentials.

Fields in `usability-trial.csv`: status, language, user type, installation complete, task configured, run/import complete, effect explained accurately, export opened outside original directory, unassisted completion, elapsed seconds, assistance and issue references. Empty fields mean unmeasured.

Acceptance is not met until the records contain five real sessions and at least four independently completed flows. Publish the measured count and limitations even if the target is missed.
