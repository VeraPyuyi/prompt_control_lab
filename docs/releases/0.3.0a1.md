# PromptControlLab 0.3.0a1

This prerelease adds a local experiment workspace: configure a task and prompts, evaluate or import outputs, optionally search with GEPA, compare the result, and export a report. The UI and examples ship inside the Python wheel.

The research workflow now includes readout sensitivity, control response profiles, measurement value, transfer prediction and portable replay. Each tool produces bilingual explanations and machine-readable results. File integrity, numerical agreement and scientific assumptions remain separate judgments.

## Installation

Download the wheel from the release assets and install from that directory:

```bash
python -m pip install "./promptcontrollab-0.3.0a1-py3-none-any.whl[ui,optimize,research]"
pcl ui --runs runs --language en
```

Use `--language zh` for Chinese. Node is needed only to develop or rebuild the frontend. The standard core remains lightweight; UI, research and GEPA are optional dependencies. A source archive is also provided for development.

Start with **Try the offline example**. It uses preset synthetic outputs and no API key. Follow the [English](../experiments.en.md) or [Chinese](../experiments.zh.md) guide for live models and imports.

## Compatibility and limits

- Existing commands and stored reports remain readable. New comparisons use versioned judgments; old `pass/clean` fields are not reinterpreted.
- Quick analysis now scores the actual withheld partition by default. Request `--evaluation-scope all` explicitly to compare all supplied items.
- Search uses training and validation data, then a locked withheld comparison. A completed search does not itself establish an improvement. The original prompt is preserved.
- Resume never automatically resends a request whose result or cost is unknown. Explicit retry covers only safely rejected calls.
- Shared or repeated sample groups disable unsupported independent significance; no paired statistics are invented from aggregate-only imports.
- Public demonstration mode is read-only. This is a local single-user release, without multi-tenant services or GPU management.

See the [acceptance record](0.3.0a1-validation.md) before labeling the release fully accepted. Human first-user trials and actual model-call checks are separate from deterministic tests. These notes are prepared for a GitHub prerelease; creating a release or uploading to PyPI has not been performed.
