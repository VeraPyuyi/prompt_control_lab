# 研究证据工作台

安装预览包：`python -m pip install "./promptcontrollab-0.3.0a2-py3-none-any.whl[ui,research]"`，
然后运行 `pcl ui --runs runs --language zh`。安装包包含界面与合成样例，使用时无需 Node 或源码目录。

## 完成第一次分析

1. 打开 **研究工具**，选择工具后点击 **载入合成样例**，或上传已有证据。样例不调用模型。
2. 查看材料能力摘要：原始记录、保存的分数和已有汇总支持不同层次的检查；来源凭证缺失会保留提示。
3. 选择分析并运行。取消会停止当前计算；恢复会保留已完成套件，从相同冻结输入和种子重算未完成套件。
   分析历史也会保留进程退出造成的中断。
4. 阅读解释，下载 JSON、CSV、中英文 HTML 或重放 ZIP。将 ZIP 导入另一工作目录即可重算所选分析。
   HTML 内嵌图表，不依赖原来的服务。

文件完整性、数值一致性、统计支持、协议前提和实际收益分别判断。负结果与未定义结果不会被隐藏；
区间包含零不能证明等效，文件哈希不能证明历史预测何时锁定。

## 五类工具分别回答什么

| 工具 | 核心问题 |
| --- | --- |
| 读出与执行条件 | 答案、解析、诊断排序和运行条件分别发生了什么变化？ |
| 控制响应画像 | 测到了什么局部响应，哪些阶段使用了标签？ |
| 测量价值 | 计入完整已记录成本后，额外测量是否值得？ |
| 迁移预测 | 新题与未见提示上的结果分别如何？ |
| 重放与性质核对 | 哪些文件、数值、协议条件与局部前提能被核查？ |

第二版明确区分原始记录与保存汇总，数字答案和 A–E 选择题使用独立版本的解析器。
固定分数前提不满足时仍展示执行条件变化，避免丢失实际观察。
五折选择统计先在每折内按提示对计算 AUC，再等权汇总，不混合不同折的分数。
未知成本保持未知，未完成批次没有发现量贡献；单项操作计时不能自动变成完整策略收益。

[输入字段、约束与合成样例](../examples/research/a2/README.md)。旧版 `/v1` 输入和原有五类工具命令继续可用。

## 命令行与本地接口

```bash
pcl research import --input evidence.zip --runs runs
pcl research run --bundle-id BUNDLE_ID --runs runs
pcl research status JOB_ID --runs runs
pcl research cancel JOB_ID --runs runs
pcl research resume JOB_ID --runs runs
pcl research export JOB_ID --runs runs
```

导入会输出材料 ID，运行会输出任务记录。也可用 `--spec analysis.json` 指定
`schema_version: "pcl.research-analysis/v1"`、`bundle_id` 和材料支持的 `analyses` 子集。
改变分析选择会建立新任务；恢复不会改变旧任务的方案。

本地接口为 `/api/research-bundles`、`/api/research-jobs`。任务下提供状态、`events`、
`cancel`、`resume` 与 `artifacts/{filename}`。上传使用
`POST /api/research-bundles?filename=evidence.zip`，请求体为文件字节，并附当前本地会话的
`X-PCL-Session`。研究分析不会执行上传脚本，也不会调用模型 API。

研究任务与普通实验共享串行队列和单个活动任务限制。每次只用一个 CPU 子进程计算一个完整套件，
数值库线程上限为一，低于本轮最多两个计算进程的上限。

## 输入与证据边界

- 支持 UTF-8 JSON、CSV、非对象类型 NPZ 与数据 ZIP。单次上传最多 64 MiB，解压后的数据合计
  最多 512 MiB，压缩包最多 10,000 项。CSV 单元格受 Python 读取器的字段长度限制。
- 检查路径、链接、数组头与体积；不执行脚本、不嵌入上传的 HTML。导入前需移除凭据字段。
- 原材料复制到选定工作目录，分析不回写输入。导出包含输入数据与已提交结果，对外分享前应检查材料内容。
- 识别出的历史辅助表格只标为已有汇总。预览有行列和文本长度限制，完整原表保留在重放包中。
- 冻结统计路径保持 20,000 次共享抽样、原种子与 18／24／22 比较家族。五套材料齐全时覆盖
  52 个主要区间，计算完成后才读取预期值。改变科学设置需要新的协议版本。
- 公开预览保持只读。新增真实研究输入和模型验收材料不随软件分发，公开样例均为合成数据。

五名首次使用者的试用仍是独立的待验收项目，自动测试和离线流程验收不能代替真人参与。
