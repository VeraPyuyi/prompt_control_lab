# 离线研究工具

五个 JSON 示例均明确标记为**合成数据**。它们可确定性运行，不调用模型、
不下载权重、不使用 GPU，也不访问正在运行的研究任务。

```console
python examples/research-tools/run_examples.py --out research-example-output
```

每个工具生成 JSON、CSV、中英文 Markdown 和 HTML。公共入口是
`promptcontrollab.diagnostics.research_tools.analyze_research(kind, document, out_dir)`。

报告包含可读指标表、来源/数值/理论前提三个独立状态卡、便携 SVG 图形和折叠的
原始 JSON。测量价值曲线在每个案例自身预算的 21 个比例点复算固定队列，并分别
列出探针、选择、扫描、排序、传输、实际完成生成的成本，不重新拟合排序规则。

- `readout`：在已保存的逐样本配对输出上比较解析规则、生成预算和解码条件。
  解析成功切换与正确性变化分别统计；保留解析器版本、事后分析声明和无定义 AUC。
  只有原始 token、逐 token 文本和完整文本严格对应时才允许派生前缀；它仍是
  保存输出的前缀，不能称为真实的较短预算生成。
- `response`：从有限、维度对齐的损失、控制向量和响应向量复算响应特征。
  正交子空间基和局部线性矩阵可选；零分母保留为空。报告显式保留读出定义、
  金标使用和校准来源；校准独立性标志只代表输入声明。
- `measurement-value`：按固定且不读取行为标签的排序，计入扫描、排序、
  探针、选择、生成和传输成本。支持逐配对变动成本、预算恰好用尽、零检查量，
  保留净发现量分解恒等式。旧版未提供传输成本时仍按原语义处理。
- `transfer`：比较冻结的完整、廉价、统一均值和零预测。所有比较共享样本
  重采样；共享端点的连通组整体重采样，不能冒充独立配对。每个模型的六项
  比较给出同时区间，并显式报告单连通组条件限制、无定义 AUC 和无效重采样。
- `replay`：读取自包含清单，分别报告文件完整性、带容差的数值复算、局部理论
  条件。不会执行任意命令、加载 pickle、读取外部路径或递归执行重放。
  可复用已有 posterior、Green、terminal-sensitivity 模块；局部条件通过
  不代表整个 LLM 的理论证明。

加 `--historical` 可复算随附的已完成历史测量价值案例；原有 54 个模型/配对、
每组 400 个样本以及来源和许可说明保留。GSM8K 迁移研究仍待独立研究流程完成，
本目录不包含其新经验结果。

独立确认需要实际嵌入并相互链接的锁定记录、评估记录和分离的队列标识。
64 位哈希本身不能证明冻结时间。即使内容和时间字段相互一致，报告仍将
`temporal_independence_verified` 保留为 `false`，不把自声明日期当作外部认证。
完整字段与公式见 [英文说明](README.md)。
